# Data card: generated benchmark packages

**Tier:** L1 (public, non-sensitive)

| Field | Value |
| --- | --- |
| Source | Generated by `scripts/generate_feed.py` from a seed. Not collected from anywhere. Three profiles (`clean-100k`, `drifted-gtfs`, `messy-export`) are built and attached to each release by `.github/workflows/release-corpus.yml` (EXP-13). |
| Licence | Apache-2.0, the repository's licence. |
| Fetch/refresh cadence | Regenerated on every release, and reproducible on demand. Each archive is byte-identical for a given seed (`tests/test_generate_feed.py` pins that), so a published checksum identifies the exact bytes a benchmark number was measured on. |
| Fetch timestamp | Each package carries a `synthetic_manifest.json` recording its seed and parameters, and a `SYNTHETIC.md` label. The release job prints the checksums into its job summary. |
| Known limitations | **Synthetic, loudly.** Every package says so in its own `SYNTHETIC.md`: "Do not cite this as evidence about what real transit feeds look like." Throughput and memory numbers in `docs/BENCHMARKS.md` are measured on these and are labelled synthetic-verified only. Real-feed calibration is #76 and is gated on an agency sharing one. |
| Retention | Indefinite (L1) as release assets; regenerable from seed regardless. |
